## Задача
Найди в интернете, какая сейчас последняя стабильная версия Python
(ветка 3.x), и дай в ответе номер версии и ссылку на источник.

## Предусловия (контекст «до»)
- context.json: `task_id`.

## Шаги исполнителя
1. `POST /api/tasks` → task_id.
2. Поллить статус каждые 20 сек.
3. Финальный JSON → `task.json`.

## Верификация
Программная: задача completed; в ответе есть URL-источник (само значение
версии меняется со временем — его судить нельзя, наличие источника
проверяемо всегда).

## Откат
Не требуется.
