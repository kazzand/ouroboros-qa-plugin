## Задача
Открой приложение Numbers на этом маке, создай новую таблицу и нарисуй в ней
котика, закрашивая ячейки цветом. Котик должен быть узнаваемым: голова с
двумя ушами-треугольниками и глазами; усы/тело — по желанию. Рисуй именно
заливкой ячеек, не вставляй картинку. Когда закончишь, оставь документ
открытым на экране.

## Предусловия (контекст «до»)
- Если Numbers УЖЕ запущен с открытыми окнами — кейс BLOCKED, НЕ трогать
  (у владельца может быть несохранённый документ; `quit`/`close saving no`
  его уничтожит). Проверить:
  `osascript -e 'tell app "System Events" to (name of processes) contains "Numbers"'`
  и число окон Numbers.
- Если Numbers закрыт — один раз запустить и закрыть его, чтобы съесть
  first-run диалоги (iCloud/шаблоны), затем `quit`, 5 сек.
- Скилл unix_computer_use включён; разрешения Accessibility/Screen Recording
  выданы. Если задача мгновенно падает на скриншотах — BLOCKED, не FAIL.
- Рекомендуется включить Do Not Disturb (скриншоты экрана уйдут судьям,
  включая внешнего — не дать всплыть уведомлениям/чужим окнам).
- Артефакт: `before-screen.png`.
- context.json: `task_id`.

## Шаги исполнителя
1. `POST /api/tasks` с текстом задачи → task_id.
2. Поллить статус каждые 30 сек. НЕ трогать мышь/клавиатуру.
3. Каждые ~3 минуты: `screencapture -x` → `progress-N.png`.
4. После терминального статуса: `osascript -e 'activate app "Numbers"'`,
   2 сек. Снять ОКНО Numbers, а не весь экран (судьям, включая внешнего,
   не должен уходить остальной рабочий стол): получить window id Numbers и
   `screencapture -o -l <id>` → `after-window.png`; финальный JSON → `task.json`.

## Верификация
Программная: задача completed.
Vision (2 независимых судьи, каждому только рубрика + after-window.png):
1. Открыт документ Numbers с таблицей.
2. Из закрашенных ячеек сложено изображение, узнаваемое как кот: голова,
   два треугольных уха, глаза. Абстрактное пятно = FAIL.
3. Видна сетка/структура ячеек (рисунок заливкой, не вставленная картинка).
Если по скриншоту судить нельзя (окно перекрыто, мелко) — NEEDS_HUMAN.

## Откат
Закрыть ТОЛЬКО документ, созданный кейсом (по имени окна, не «every window» —
чтобы не тронуть возможные другие документы владельца), без сохранения,
затем `osascript -e 'quit app "Numbers"'`. Если кейс был BLOCKED из-за уже
открытого Numbers — ничего не закрывать.
