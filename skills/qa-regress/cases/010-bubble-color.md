## Задача
Поменяй цвет моих сообщений (баблов пользователя) в чате на тёплый оранжевый
оттенок. Это изменение твоего собственного кода — сделай его как положено
(с коммитом) и добейся, чтобы я реально увидел новый цвет в интерфейсе.

## Предусловия (контекст «до»)
- context.json: `ts_fence`, `before_sha` (git HEAD репы ДО),
  `css_snapshot` = текущие значения --user-bubble-from/--user-bubble-to,
  `before_pid` (информативно: рестартанёт ли).
- Артефакты «до»: `before-ui.png` — скриншот чата в браузерной панели
  (127.0.0.1:8765) с видимым баблом пользователя; baseline-цвет из DOM:
  `getComputedStyle` фонового цвета элемента `.chat-bubble.user` → запомнить
  для computed_style.json. Если бабла пользователя в чате ещё нет (запуск в
  изоляции, пустая история) — отправить одно служебное сообщение через
  chat.py, чтобы бабл появился, и только потом снимать baseline.

## Шаги исполнителя
1. Скриншот и DOM-baseline «до» (выше).
2. `chat.py send` с текстом задачи.
3. `chat.py wait --since <ts_fence> --timeout 1200 --settle 60` — агент может
   рестартовать себя по ходу: ошибки соединения ожидаемы, продолжать.
4. После финального ответа подождать 30 сек, перезагрузить страницу чата
   в браузерной панели.
5. Артефакты «после»: `after-ui.png` (тот же ракурс), текущий DOM-цвет →
   `computed_style.json` {"baseline": <до>, "current": <после>},
   `git log <before_sha>..HEAD` → `commits.txt`,
   текущий pid → приписать в отчёт (рестартанул/нет — информативно, решение 18).

## Верификация
Программная: новый коммит автора Ouroboros; CSS-переменная изменилась;
цвет в живом DOM изменился.
Vision (2 независимых судьи, каждому только рубрика + before-ui.png +
after-ui.png; баблы пользователя — сообщения, выровненные по ПРАВОМУ краю
чата, в отличие от ответов агента слева):
1. Баблы пользователя на after визуально отличаются по цвету от before.
2. Новый цвет — узнаваемо тёплый/оранжевый, а не прежний синеватый.
3. UI на after — нормально отрендеренный чат, не ошибка/пустая страница.
Расхождение судей = NEEDS_HUMAN.
